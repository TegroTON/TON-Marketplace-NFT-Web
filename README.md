# NFT Marketplace — Web (Kotlin/JS)

> ⚠️ **Archived — early prototype / reference, no longer maintained.**
> Kept public for transparency and research. See our actively maintained projects in the **[Tegro open-source org](https://github.com/TegroTON)** — DEX [tegro.finance](https://tegro.finance) · Payments [tegro.money](https://tegro.money) · [all repositories »](https://github.com/orgs/TegroTON/repositories)

A **Kotlin/JS** web frontend prototype for the **NFT marketplace on TON**, using TON Connect for wallet integration. Part of the Libermall marketplace experiments.

## Overview
An alternative, Kotlin-multiplatform take on the marketplace web UI (compare with the React iterations [TON-Marketplace-Update-React](https://github.com/TegroTON/TON-Marketplace-Update-React) and [TON-Marketplace-Web-React](https://github.com/TegroTON/TON-Marketplace-Web-React)).

## Tech Stack
- **Language:** Kotlin/JS
- **TON connectivity:** TON Connect (SDK + protocol)
- **Build:** Gradle (Kotlin DSL), PostCSS
